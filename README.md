# homebrew-mcptoon

Personal Homebrew tap for [mcptoon](https://github.com/activeing123/mcptoon) — an MCP client that keeps tool schemas out of the model context (TOON manifests). Maintained by the upstream author.

## Install

```sh
brew tap activeing123/mcptoon
brew install mcptoon
```

Then verify: `mcptoon --version`.

Upstream docs: English [README](https://github.com/activeing123/mcptoon#readme) · 中文 [README.zh-CN](https://github.com/activeing123/mcptoon/blob/main/README.zh-CN.md)

> Note: for the PyPI route (`pipx install mcptoon` / `uv tool install mcptoon`) nothing here is required; this tap exists for people who prefer `brew`.
